# The Tao Te Ching, Chapter 36

The Subtle Light

If you would shrink a thing, you must first let it stretch wide. If you would weaken a thing, you must first let it grow strong. If you would lay a thing low, you must first let it rise high. If you would take a thing away, you must first give to it. This is called the subtle light.

The soft and weak overcome the hard and strong.

Fish should not leave the deep water; and the sharp tools of a state should not be put on show before the people.
