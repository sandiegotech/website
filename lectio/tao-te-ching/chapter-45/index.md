# The Tao Te Ching, Chapter 45

Great Perfection Seems Flawed

Great perfection seems flawed, yet its use never wears out. Great fullness seems empty, yet its use never runs out. Great straightness seems bent. Great skill seems clumsy. Great eloquence seems to stammer.

Movement overcomes the cold; stillness overcomes the heat. Purity and stillness set the world right.
